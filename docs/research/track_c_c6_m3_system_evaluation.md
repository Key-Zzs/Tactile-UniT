# Full Track C — C6 Final M3 System Evaluation

C6 is a freeze-only composition of accepted C1–C5 evidence. It trains no
component, performs no model selection, and does not promote the C5 causal
Vision diagnostic into runtime. The canonical missing-Contact route is the
frozen Action-only `FALLBACK_A` model.

The current 17,504-row set is a **locked engineering benchmark**, not an
untouched or publication final test. C6 therefore records internal M3 status
separately from external generalization confirmation.

The canonical runtime has exactly three outcomes: `FULL_AH` for planned Action
plus current Contact context, `FALLBACK_A` for planned Action without current
Contact, and `ABSTAIN_NO_ACTION` without a plan. Future Vision is only an
offline upper bound; current causal Vision remains diagnostic-only because its
correct-context-use gate was not established.

The closure evaluator and its deterministic evidence are in
`scripts/tactile_unit/evaluate_c6_m3_system.py` and
`.local/artifacts/tactile_unit/vac_c6/` respectively. The tracked system
manifest, limitations, and future protocol define the permitted claim boundary.
